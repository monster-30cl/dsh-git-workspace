# dsh-git-workspace

简体中文 | [English](README_EN.md)

## 概要

这个插件在右侧栏提供统一的“审查”页面，用于查看提交历史、文件差异、待推送提交和工作区更改。会话头部的分支入口可以切换本地或远程分支，并可打开完整分支页面。Host 通过 dsh 的 Workspace 与 subprocess 服务执行 Git，浏览器代码不直接运行命令。插件启动时只读取仓库状态，不会自动修改工作区。

<a id="安装"></a>
## 安装

### 从 GitHub 源码安装

需要 Node.js 22.19 或更高版本。

```powershell
git clone https://github.com/monster-30cl/dsh-git-workspace.git
cd dsh-git-workspace
corepack enable
pnpm install
pnpm run check
pnpm pack
```

构建完成后，在桌面端菜单中打开“桌面插件…”，把生成的 `monster-30cl-dsh-git-workspace-0.1.0.tgz` 绝对路径填入安装框并执行安装。Desktop 的保留 profile 由 Electron 独占，不能通过 `dsh plugin --profile desktop` 修改。

安装完成后启用“Git 工作区”插件并重启桌面端。宿主必须已经注册会话对应的 Workspace；普通目录可以打开界面，但 Git 操作会显示该目录不是工作树。

### 从 Release 安装

每个 `v*` 标签会生成一个 `.tgz` Release 附件。下载附件后，在桌面端“桌面插件…”窗口中输入 tarball 的绝对路径，例如 `C:\path\to\monster-30cl-dsh-git-workspace-0.1.0.tgz`，然后执行安装。

<a id="使用"></a>
## 使用

### 提交历史与筛选

- 在右侧栏开始页点击“审查”，同时查看提交历史和工作区更改。
- 搜索框按提交说明过滤，作者下拉框按提交作者过滤；两者可与日期区间叠加使用，也可分别清空。
- 点击“日期”展开日期选框。只选起始日期表示“该日及之后”，只选结束日期表示“该日及之前”，两个都选表示区间内；起止日期均包含当天，按 Git 的提交时间过滤。
- 日期选择使用跟随界面主题的日历，支持切换月份、“今天”和单个日期清除。日历在顶层显示，并在窗口边缘自动避让；点击外部或按 Esc 可关闭日历。
- 日期栏右侧的“×”只清除已选中的起止日期，保留日期选框展开。日期已为空时，不会重复查询。
- 点击提交可查看文件列表、所选文件的前后内容和补丁。代码区支持 Ctrl + 滚轮放大、缩小文字，也支持设置中选择的附加按键（默认 Alt）。左右代码区默认同步横向和竖向滚动；标题栏的同步滚动按钮同时开启或关闭两个方向的联动。

### 工作区更改与提交备注

- “代码提交”区域支持提交、提交并推送、拉取、推送、搁置和回滚，文件勾选决定本次操作范围。
- “未进行版本管理的文件”列表默认折叠，标题保留文件数量。未跟踪文件不能勾选提交；点击文件右侧的“＋”（加入版本管理）后，文件暂存并移入“更改”列表，才可参与提交。全选、批量操作和 AI 备注仅包含“更改”列表中勾选的文件。
- 回滚尚未提交的新增文件时，只取消版本管理并保留磁盘内容，文件回到未跟踪列表；已有文件仍恢复到上次提交。
- 提交、提交并推送或搁置时需要填写备注；有上次成功操作的备注时，可点击回填按钮复用。
- 在“提交”或“提交并推送”的备注窗口中，点击标题右侧的星光图标，生成本次勾选文件的提交备注。悬停提示为“AI 生成提交备注”；生成中显示加载图标，完成后自动填入输入框，可继续修改后确认提交。
- AI 生成使用宿主已配置的默认模型，基于勾选文件列表和差异生成中文备注。生成本身不会提交或推送代码，也不会修改 Git 暂存区。
- 关闭备注窗口、修改文件勾选范围或编辑备注会取消旧请求，避免生成结果覆盖新的输入。生成失败会显示原因，可重试或手动填写。

### 分支操作

- 点击会话头部的分支名称可切换分支；菜单末尾可打开完整分支页面。
- 完整分支页面支持选择 Workspace、刷新分支、新建分支和检出远程分支。

<a id="安全边界"></a>
## 安全边界

提交、推送、拉取、搁置、恢复和分支切换会修改共享 Workspace。插件在执行分支切换前请求确认。回滚未提交文件和删除搁置可能永久丢失数据，请先检查选中的文件。Host 只接受已注册的 Workspace id，并将路径限制在对应 Workspace 内。

仅在点击 AI 生成图标后，插件才会将本次勾选文件的列表和差异发送给默认模型对应的服务商。生成结果需由用户检查后确认提交。

<a id="兼容性"></a>
## 兼容性

当前构建面向 DeepSeek Harness Desktop `0.2.1-rc.3` 的客户端服务和图标命名，并已在兼容 DSH 环境中验收。AI 生成依赖宿主的 LLM 服务和默认模型配置；未配置模型时会提示原因，仍可手动填写备注。`pnpm run check` 检查面板注册、AI 接口接线及 Remote 类型标识；这些检查不能替代实际宿主启动和真实模型调用验证。这个仓库不保证命令行纯 headless profile 能显示客户端界面。

<a id="开发与打包"></a>
## 开发与打包

```powershell
corepack enable
pnpm install
pnpm run build
pnpm run verify
pnpm run pack:release
```

`packages/controller` 提供 Workspace 范围内的 Git Remote；`packages/panel` 提供右侧审查页、分支菜单和设置注册。undefined构建脚本只读取仓库内文件，不依赖维护者机器上的 Harness 路径。

## Model Experience

该 bundle 提供桌面端 Git 界面与 Host 操作，不向会话模型注册工具，也不会自动启动对话。用户点击 AI 生成图标时，插件会发起一次独立的模型请求，以勾选文件的差异生成中文提交备注；该请求不会执行代码修改或 Git 提交。

## Known Limitations and Deferred Work

插件依赖宿主提供的 Workspace、subprocess、Remote 和右侧栏客户端服务。不同桌面宿主升级这些服务时，可能需要更新兼容适配并重新发布。

AI 备注每次最多分析 60 个文件；较长差异会截断，二进制文件仅提供文件信息，不分析二进制内容。生成请求最长等待 90 秒，结果可能遗漏细节，应以实际差异为准；内容、费用及可用性取决于宿主配置的模型服务。
